The Moon finally answers back. After four billion years of being wished upon, howled at, and blamed for every tide, sleepless night, and missed deadline, the Moon gets one line to reply — and it is tired, cratered, and still doing all the tides by itself.

> You wished on me for four billion years and never once asked how I was doing — I'm fine, by the way. Tired, cratered, and still doing all the tides by myself.

## Run it

```sh
python3 main.py
```

The program prints the line and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when the harness sets it). Standard library only, deterministic — the same line on every run.
